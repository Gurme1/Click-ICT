About ClickICT Project

ClickICT is a pioneering educational platform designed to provid Computer technology educational in Afaan Oromoo(Oromo language). This project addresses the critical need for localized tech content in one of Africa's most widely spoken languages.

Key Features:

  • Comprehensive admin dashboard for content management
  • User registration and comment system
  • Responsive design for all devices
  • Email notification system
  • Multi-category content organization
  • Image upload and management

Seenaa Keenya (About Us)

ClickICT kan hundeeffame rakkoo beekumsa teeknoloojii fi hawaasa keenya gidduu jiru dhiphisuufi. Addunyaan keenya saffisaan gara dijitaalaatti jijjiiramaa osoo jirtuu, hawaasni keenya afaan dhalootaatiin odeeffannoo teeknoloojii amansiisaa fi qulqullina qabu akka argatu gochuun kaayyoo keenya isa ijoodha.

Nutis garee ogeessota teeknoloojii, pirograamaroota fi namoota dhimma kanaan jaalala qabaniin kan ijaarramne yoo ta''u, barnoota Kompiitaraa, teeknoloojii bilbilaa fi kalaqa AI (Artificial Intelligence) karaa salphaa ta''een isiniif dhiyeessina. ClickICT madda beekumsaa ammayyaa dhaloota har''aaf qophaa''edha.
